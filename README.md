# Silent_Emergency_Help
🚨 Excited to share our MCA major project — “Silent Help: Hidden Emergency Signal App” 📱

A smart Android safety application designed to help users send emergency alerts secretly during dangerous situations.

✨ Features:
🔐 Fake Calculator Interface
📍 Live Location Sharing
📳 Shake Detection SOS
🔘 Power Button Trigger
📞 Automatic Emergency Calling
💾 Secure Offline Data Storage

Built using Android Studio, Java/Kotlin, SQLite, and Google Maps API.

This project focuses on personal safety, privacy, and fast emergency response.
