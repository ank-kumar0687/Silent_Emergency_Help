# Silent Help – Hidden Emergency Signal App

Silent Help is an Android-based emergency safety application designed to provide quick and discreet help during dangerous situations. The app allows users to trigger SOS alerts secretly using hidden actions like shake detection, power button presses, or a fake calculator interface.

 📱 Features

- 🔐 Fake Calculator Interface for hidden access
- 🚨 Secret SOS Trigger using predefined code
- 📳 Shake Detection for emergency activation
- 🔘 Triple Power Button Press SOS trigger
- 📍 Live GPS Location Sharing via SMS
- 📞 Automatic Call to Primary Emergency Contact
- 👥 Emergency Contact Management
- 🕒 SOS Alert History
- 👤 User Profile Management with Photo
- 💾 Secure Local Data Storage using SQLite / Room Database
- 🌐 Works even without internet connectivity
